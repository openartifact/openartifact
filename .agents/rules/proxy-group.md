# Proxy and group repos

- **One pipeline per side; formats only supply hooks.** Proxy (`internal/proxy/pipeline.go`): describe each upstream document as a `metaDoc` (key, URL, fetch options and verify, limit, `bad` = what an unparsable copy means) and serve it with `serveVerbatim` (byte for byte), `serveRendered` (`render` + `etag`; an error wrapping `errUnusableDoc` drops the row and answers 502) or `serveDownload` (a `locate` hook that reads the CACHED metadata through `parseDoc` and returns the URL plus the digest the bytes must match; `noAuth` for foreign origins is forced centrally, SSRF validation happens in `fetchURL`). Generated documents go through `serveGenerated`. Never hand-roll resolve, Vary/stale Warning, `base.Revalidate`, blob read under `s.packuments` or the origin check in a format file. Group (`internal/group/pipeline.go`): a merged document is a `mergedDoc` (ask, merge hook, content type, max-age) served by `serveMergedDoc`; formats whose tail differs use `collect`/`askMember`/`writeNoDocument`/`writeMerged`, never their own capture loop or ETag code. Hosted wins stays in `hostedwins.go`. Formats that mirror the upstream path by path (apk, deb, ivy, maven, nix, pacman, rpm, sbt) use the generic `Serve` route and `fetch`/`fetchURL`; docker is the OCI path.
- **Proxy/group repos:** the `Proxy` and `Group` flags of a format's `Spec` in `internal/repotype` say whether it can be a proxy or a group (today every format can be both; `registry_test.go` freezes the sets) (deb/rpm/apk/pacman groups merge their metadata in `internal/worker/group_metadata*.go` and serve it from `internal/group/debrpm.go` and `pacman.go` / `apk.go`; an apk group re-signs each merged index with its own `internal/apkkeys` key, and is not in `hostedwins.go`: the merge drops proxy entries of hosted names; `internal/repotype` is the single policy, enforced at creation). `internal/repodispatch` middleware serves them in front of the format handlers; hosted repos pass straight through. A new proxy/group format must be added to `repotype` and to the dispatch map in `cmd/server/main.go`. Docker is the exception to path mirroring: its proxies/groups are served only under `/v2` (`repodispatch.OCIMiddleware` → `proxy.ServeOCI` / `group.ServeOCI`) and `/repos/{name}` answers 404 for them; everything read-only goes through `ocipath.RejectNonPull`.
- **Nix proxy/group** (`internal/proxy/nix.go`, `internal/group/nix.go`): proxy keeps narinfo/`nix-cache-info` byte-for-byte (upstream signatures pass through) and caches a NAR only after it matches the narinfo `FileHash`/`FileSize` (a sidecar cache entry records the expectation); a group asks hosted members first, appends its own signature to hosted members' narinfo (`internal/nixkeys`, `WithNixKeys`) and passes proxy narinfo through unsigned; not in `hostedwins.go`.
- **Terraform proxy/group** (`internal/proxy/terraform*.go`, `internal/group/terraform.go`): the proxy handles every hosted registry path itself and stores everything in `proxy_cache_entries` (no schema). The repository name is the upstream namespace (provider types need it). Module archives and provider files live on other hosts and are fetched on first use through download tickets: `terraform.Minter` mints them, the hosted `/terraform/dl/` route redeems them and hands a proxy repository's ticket to `proxy.Service.ServeTerraformDownload` (`terraform.ProxyServer`). Provider zips must match the document `shasum` and the upstream `SHA256SUMS` before they are stored and keep the upstream's signing keys; module archives are pinned to the digest of the first copy; module sources are `github.com` repositories (mapped to codeload tarballs) and plain archive URLs, both with `//subdir`; they are repacked by `terraform.RepackModuleArchive` (wrapper stripped, hosted archive limits, no links) before the pin applies, and other getters answer 501. Every parser has a fuzz target with seeds in `internal/proxy/testdata/fuzz` and terms in `.clusterfuzzlite/dicts/internal_proxy.dict`.
- **Composer proxy/group** (`internal/proxy/composer.go`, `internal/group/composer.go`, grammar and rendering in `pkg/composer` `ParsePath`/`RenderSource`/`RelinkMember`): the proxy caches the upstream p2 document verbatim under `p2/VENDOR/NAME[~dev].json` (validated by `ParseDocument`) and renders it per request (expand, `dist.url` repointed at `/repos/REPO/dists/VENDOR/NAME/VERSION/REF.zip`, minify; ETag from blob key + base URL), so the cache never depends on `baseUrl`. `packages.json` is generated (`metadata-url` only; no list/search/available-packages). `REF` is `Dist.ProxyRef` (sha256 of the upstream dist URL + reference): a dist is fetched only from the URL the cached p2 publishes for that version (`composerPublishedDist`), a request whose `REF` differs is a 404 without a negative cache entry; `noAuth` when the dist URL is another origin than `upstream_url` (credentials never go to GitHub/codeload); a non-empty `dist.shasum` is verified (sha1) before the blob is stored, otherwise the reference vouches for it; keys `dists/...` of released versions are `Immutable` (`composerDistImmutable`), branches use the TTL; non-zip dists are dropped from the served metadata (Composer falls back to `source`). The group merges p2 by `Version.MergeKey` (first member wins, hostedwins `composerRef` probes the stable then the `~dev` document), relinks with `RelinkMember` and lets dist downloads fall through to first-hit (only the member that published the version has that `REF`); `available-packages` only when every readable member is hosted and lists it.
- **Ansible proxy/group** (`internal/proxy/ansible.go`, `internal/group/ansible.go`): the proxy serves the Galaxy API v3 from the upstream (default `https://galaxy.ansible.com`) and stores everything in `proxy_cache_entries` (no schema); every link is regenerated with `pkg/ansible` `Links`, never reused from the upstream. Cache keys: `api/v3/collections/NS/NAME/versions/` (the combined, normalized version list of all upstream pages), `api/v3/collections/NS/NAME/versions/VERSION/` (the upstream detail document, validated by `ParseVersionDoc`, relinked at serve time) and `api/v3/artifacts/collections/FILE` (the tarball, immutable, cached only when its sha256 equals the detail's `artifact.sha256`; `noAuth` when the download URL is another origin). The collection index is 404 on a proxy. The group relinks every member answer to itself, merges versions in member order (earlier wins), serves versions, details and downloads of a collection a readable hosted member holds from the hosted members only (`hostedwins.go`, unless `MergeProxyVersions`), and merges the index over hosted members only.
